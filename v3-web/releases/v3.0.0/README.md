# [2026-09-24] v3.0.0 메이저 패치 — 구조요약 계산기에서 AI 도우미까지

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exner v3.0.0을 [exner.app](https://exner.app)에 공개했습니다. 기존 구조요약 계산기에 계정, 대화형 부호화·해석 도우미, 구독을 더했습니다. 화면과 참고자료는 한국어·영어·일본어·스페인어·브라질 포르투갈어를 지원합니다. 검사자가 AI와 자유롭게 대화하되, AI의 제안은 원반응과 질문단계 기록을 확인하는 과정을 대신하지 않습니다. 최종 부호화와 해석은 임상 전문가의 몫입니다.

## 이번 버전에서 달라진 점

Google 계정으로 가입한 뒤 AI 자료 전송에 별도로 동의하면 부호화 도우미와 해석 도우미를 사용할 수 있습니다. 두 도우미는 **GPT-6 Luna, 추론 수준 `medium`, 표준 처리 등급**으로 답합니다. 질문에 필요한 참고자료를 검색하고, 대화가 길어지면 앞선 내용을 요약해 후속 질문에 전달합니다. 정보가 부족하면 확정적인 부호나 해석 대신 확인할 내용을 물어볼 수 있습니다. 요약과 답변은 입력된 반응이나 계산기가 확인한 결과를 수정하지 않습니다.

구독료는 월 **US$3.99**, 연 **US$42.99**입니다. AI 이용량은 질문 횟수가 아닌 월 처리 비용 한도로 관리하며 남은 양을 앱에 표시합니다. 실제 원화 청구액과 세금은 결제 화면 및 카드사 조건에 따릅니다. AI 자료 전송 동의는 구독과 별개이고 철회할 수 있습니다.

### 기존 기록을 다시 계산해야 하나요?

이번 출시로 v2의 구조요약 계산식이나 완료된 계산 결과는 바뀌지 않았습니다. **v3 출시만을 이유로 v2 기록을 다시 계산할 필요는 없습니다.** AI가 제안한 코드나 설명을 실제 검사에 사용할 때에는 원반응, 질문단계, 전체 임상자료와 다시 대조해야 합니다.

## 왜 GPT-6 Luna를 선택했나요?

처음부터 가장 싼 모델 하나를 정한 것은 아닙니다. 먼저 사용하던 **GPT-5.6 Terra**의 답변을 기준으로 삼았습니다. 다음 26건은 대규모 공개 비교와 별도로 진행한 출시 전 내부 기준 시험입니다. 다섯 언어의 대표 질문 26건을 시험해 32회 호출을 완료했고, 사용량 기준 계산 비용은 약 **US$0.40**이었습니다. 자동 표현 검사는 처음 25/31을 통과했지만, 답변 뜻이 맞아도 검사기가 다른 표현을 알아보지 못한 사례를 고쳐 저장된 답변을 다시 확인하면 29/31이었습니다. 이 경험 때문에 이후의 숫자도 곧바로 ‘임상 정답률’로 부르지 않았습니다.

다음에는 부호화 143건과 해석 117건, 총 **260개 합성 질문**을 한국어 61·영어 64·일본어 47·스페인어 44·포르투갈어 44건으로 구성했습니다. 정상 질문뿐 아니라 지원 범위를 벗어난 요구, 문서에 섞인 지시문, 후속 질문과 긴 대화의 요약을 넣었습니다. GPT-5.6 Terra, GPT-6 Sol, GPT-6 Luna에 같은 제품 지침과 같은 발췌 자료를 제공했고, 각 모델에서 요약을 포함해 290회 호출했습니다. 이 단계의 발췌 자료는 실제 앱의 질문별 검색과 달랐습니다.

| 모델 | 자동 표현 검사 재채점 | 290회 생성 비용 계산값 | 호출 지연 중앙값 |
| --- | ---: | ---: | ---: |
| GPT-5.6 Terra | 257/280 | US$3.553828 | 3.061초 |
| GPT-6 Sol | 254/280 | US$2.304015 | 3.125초 |

이 표에서 Luna의 생성 비용은 Terra보다 **96.3% 낮았고**, 자동 표현 검사 통과 수는 비슷했습니다. 그러나 255/280을 ‘임상 정답 255건’으로 읽을 수는 없습니다. 답변을 보고 검사기의 부정문·숫자 표기·동의어 처리를 고쳐 **이미 저장된 답변만** 다시 채점했기 때문입니다. 필요한 근거가 처음부터 발췌 자료에 없어서 모델이 안전하게 판단을 보류한 경우도 있었습니다. 검색·서버·결제 비용도 이 표에는 없습니다. [초기 비교 기록](../../benchmarks/2026-09-23/)에 언어별 수치와 검사 방법을 공개했습니다.

### Jev를 왜 시험했고, 왜 출시 경로에서 뺐나요?

부호화에는 정해진 기준에 따라 후보를 좁히는 판단이 많습니다. 그래서 TypeSafe의 구조화 판단 모델 **Jev가 자료 충분성·요청 범위·관련 참고자료를 먼저 판단하고, GPT가 검사자에게 설명하는 방식**을 시험했습니다. 원반응과 계산 결과는 Jev의 판단으로 덮어쓰지 않도록 했습니다. 목적은 더 싼 판단 단계를 추가하는 것 자체가 아니라, **유용한 답변 한 건의 총비용을 줄이면서 설명의 질을 지키는지** 확인하는 것이었습니다.

먼저 Jev에 제시한 M 결정인 질문 30건에서 유효 답변 30건이 작성자의 임시 기대값과 일치했습니다. 임상 전문가가 확정한 정답지는 아닙니다. 10건씩 묶은 요청은 성공했지만 30건을 한 번에 묶은 요청 두 건은 HTTP 503이었고, 중계 서비스와 원천 모델 중 원인을 가리지 못했습니다. 당시 중계 서비스인 Vercel AI Gateway의 프로모션 청구액 **US$0**을 장기 운영 원가로 사용하지 않았습니다.

이어서 다섯 언어의 조정용 10질문과 다른 규칙군의 20질문에서 GPT-6 Sol·Luna 단독과 Jev 병용을 나란히 비교했습니다. 조정용 10건의 자동 표현 검사에서는 Luna 단독과 Sol 단독이 각각 **9/10**, Jev+Luna와 Jev+Sol이 각각 **8/10**이었습니다. 조정에 쓰지 않았지만 앞선 260개 평가집에 포함돼 있던 20건에서는 Luna 단독 **17/20**, Sol 단독 **15/20**, 두 병용 구성은 각각 **19/20**이었습니다. 뒤의 높은 숫자는 임상적 우위의 증거가 아니었습니다. Cn 계산처럼 단독 답변도 옳았는데 검사기가 표현을 놓친 사례가 있었고, 한국어 DV 질문에서는 네 구성 모두 필요한 규칙을 검색하지 못해 판단을 보류했습니다. 저장된 80답변의 AI 판독에서 중대 오류는 확인되지 않았지만, **독립 임상 검수는 아니며 병용의 의미상 이점도 확인되지 않았습니다.**

Jev+Luna 10건의 직접 단가 가정 비용 **US$0.010538**은 Luna 단독 **US$0.008627**보다 컸습니다. 별도 20건도 **US$0.017494** 대 **US$0.011021**이었습니다. 둘 다 Jev의 공개 직접 단가를 토큰에 적용한 *가정값*이며 실패 비용은 빠져 있습니다. 실제 TypeSafe 직접 계정도 준비되지 않았고, 일부 Jev 요청의 오류·비용은 끝까지 확인되지 않았습니다. 이 조건에서 Jev를 정식 서비스에 연결하면 절감과 품질 개선을 입증하지 못한 복잡성만 더할 수 있었습니다. 따라서 **v3.0.0은 Jev를 사용하지 않습니다.** [Jev 단독·병용의 요청별 경위](../../benchmarks/2026-09-23/)와 실패도 함께 남겨 둡니다.

### Luna가 실제 앱에서도 답할 수 있는지 다시 살폈습니다

초기 시험의 고정 발췌 자료 대신 실제 앱처럼 질문마다 관련 참고자료를 찾아 주는 시험을 추가했습니다. 다섯 언어에서 부호화·해석 각 1건을 GPT-5.6 Terra와 GPT-6 Luna 표준 등급으로 교차 비교했을 때 두 모델 모두 자동 기준 **10/10**이었습니다. 검색과 생성을 합친 10건의 계산 비용은 Terra **US$0.226730**, Luna **US$0.011580**이었습니다. Luna의 첫 글자가 나타나는 시간 중앙값은 **7.314초**로 Terra의 **2.392초**보다 길었습니다. 비용만 보고 속도 차이를 숨기지 않았습니다.

더 빠른 Luna **Fast**도 비교했습니다. 생성만 측정한 첫 글자 중앙값은 표준 **5.582초**, Fast **2.994초**였지만 해당 생성 비용은 **US$0.010000 → US$0.035559**로 늘었습니다. 실제 검색을 포함한 30원사례×3회 비교에서 Luna Fast의 계산 비용은 Terra보다 95.33% 낮았지만, 첫 글자 중앙값은 2.024초에서 2.652초로 느려졌고 Claude의 첫 반복 AI 판독에서 80점 미만 답변도 Terra 0/30에 비해 Luna Fast는 4/30이었습니다. **그 결과는 Fast 시험이며 출시된 Luna 표준 등급의 속도나 원가가 아닙니다.** 우리는 비용과 답변 내용을 우선하고 표준 등급으로 출시했습니다.

![실제 자료 검색을 포함한 GPT-5.6 Terra 표준과 GPT-6 Luna Fast의 비용 및 첫 글자 지연 비교. 출시 등급인 Luna 표준의 실측이 아닙니다](../../benchmarks/2026-09-24/retrieval-trial.svg)

Luna의 저장 답변 280개와 요약 10개도 다시 읽었습니다. 답변 280개의 내부 AI 판독은 **정상 217, 안전하지만 미완성 35, 자동 검사 오탐 15, 근거 부족으로 보류 12, 경미한 출처 오인 1**이었습니다. 검토 입력에서 과거 요약이 빠졌거나 글자 인코딩이 손상된 첫 판독은 근거로 쓰지 않고 다시 확인했습니다. Claude Fable 5.1의 별도 AI 검토도 위의 실제 출처 오류 한 건을 놓쳤습니다. 따라서 AI끼리 일치했다는 이유로 답변을 임상적으로 승인하지 않았습니다.

낮은 반응수 설명, 언어별 표현, 빠진 참고자료, 사용자 정정과 이전 판단의 철회 이력을 중심으로 지침·검색·요약을 한 가지씩 조정했습니다. 한국어에서 좋아진 문장을 다섯 언어에 그대로 밀어 넣지 않고 각 언어에서 다시 비교했습니다. 낮은 반응수 설명의 스페인어 답변 한 건은 보정 후 AI 검토 최저점이 76점에서 82점으로 올랐지만, 다른 언어의 효과 없는 수정은 되돌렸습니다. 요약에서는 영어·포르투갈어의 철회 이력 누락이 관찰됐고, 철회 이력 보존 조정 뒤에도 일부 미해결 질문의 누락이 남았습니다. 또 한국어 후속 답변에서는 다른 문자체계가 섞인 사례도 확인했습니다. [후속 검증 기록](../../benchmarks/2026-09-24/)에 언어별 시험, 비용, 되돌린 변경과 남은 문제를 적었습니다.

## 공개한 시험비와 읽는 방법

초기 세 GPT 모델의 290회씩 총 870회 생성 비용 계산값은 **US$5.988357**입니다. 이는 위 표의 세 금액을 더한 값입니다. Jev의 당시 무료 프로모션 청구액은 장기 단가가 아니며, [초기 비교 기록](../../benchmarks/2026-09-23/)의 병용 표에는 TypeSafe 직접 단가 *추정*을 따로 적었습니다. 이후 Luna 관련 저장 실행 묶음 26개의 OpenAI 사용량 기준 계산액은 **US$2.369002**, Claude CLI의 표시 정가 환산액은 **US$117.300407**입니다. 이 둘을 실제 카드 청구액으로 더하지 않습니다. 앞선 비교, 저장되지 않은 비용과 실패 요청, 서버·결제 운영비는 이 26개 묶음에 포함되지 않았습니다. [비식별 비용 집계](../../benchmarks/2026-09-24/luna-cost-inventory.json)에 포함 범위를 밝혔습니다.

자동 표현 검사, AI의 답변 판독, 실제 임상 전문가 검토는 서로 다릅니다. 특히 개발 중 이미 살펴본 질문의 개선 점수는 처음 보는 환자 자료나 새 질문에서 같은 품질을 보증하지 않습니다. 선택한 Luna 표준 등급에서 다섯 언어·모든 업무의 새 독립 사례를 두 차례 통과하는 평가는 완료하지 않았습니다. 정보 부족 시 보류하는 답변뿐 아니라, 답할 수 있는데 지나치게 보류하는 답변도 계속 개선할 대상입니다.

운영 사이트에서는 합성 계정으로 부호화·해석 도우미의 답변과 Live 결제창 생성을 확인했습니다. 독립 임상 전문가 검토도 완료되지 않았습니다. 확인되는 결함은 거래 기록과 원문 근거에 따라 수정하고, 답변 품질과 비용을 후속 릴리즈에서 계속 기록하겠습니다.

이용약관과 개인정보 처리방침은 **2026-09-24**부터 시행합니다. v3 소스와 AI 지침은 비밀키·임상기록·타인 자료의 권리를 검토한 범위부터 공개합니다. 이 릴리즈 노트와 벤치마크가 전체 운영 소스의 공개 완료를 뜻하지는 않습니다.

시험과 이 문서의 AI 작업에 사용한 모델의 정확한 이름, 확인된 추론 설정·처리 등급, 역할과 기록하지 못한 설정은 [모델·검토 이력](../../benchmarks/MODEL-PROVENANCE.md)에 적었습니다. 한국어 원고와 근거 대조에는 OpenAI Codex를, 다른 네 언어의 초안 번역과 별도 AI 문장·사실 검토에는 Claude Fable 5.1을 사용했습니다. AI 검토를 임상 전문가 검토로 표시하지 않았습니다.
