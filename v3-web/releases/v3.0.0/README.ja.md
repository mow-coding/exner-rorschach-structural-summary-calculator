# [2026-09-24] v3.0.0 メジャーリリース — サービス提供のAI利用枠とサブスクリプション

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exner v3.0.0を[exner.app](https://exner.app)で公開しました。
v2では利用者が自身のOpenAI APIキーを接続して符号化・解釈アシスタントを使用していました。v3ではサービスが提供するAI利用枠で利用できます。Googleアカウント、会話の保存、月額・年額のサブスクリプションも導入しました。構造一覧表計算機と参照文書は、登録せずに無料で利用できます。画面と参照資料は韓国語・英語・日本語・スペイン語・ブラジルポルトガル語に対応しています。検査者はAIと自由に対話できますが、AIの提案は原反応と質問段階の記録を確認する過程の代わりにはなりません。最終的な符号化と解釈は臨床の専門家が担います。

## このバージョンで変わった点

Googleアカウントで登録し、利用規約とプライバシーポリシーに同意すると、符号化アシスタントの体験用利用枠が一度だけ提供されます。サブスクリプションでは、両アシスタントで共有する月間利用枠が提供されます。両アシスタントは**GPT-6 Luna、推論レベル`medium`、標準処理区分**で回答します。質問に必要な参照資料を検索し、対話が長くなると、それまでの内容を要約して後続の質問に引き継ぎます。情報が不足している場合は、確定的な符号や解釈の代わりに、確認すべき内容を尋ねることがあります。要約と回答は、入力された反応や計算機が確認した結果を修正しません。

サブスクリプション料金は月額**US$3.99**、年額**US$42.99**です。AIの利用量は質問回数ではなく月間処理費用の上限で管理し、残量をアプリに表示します。実際のウォン建て請求額と税金は、決済画面およびカード会社の条件に従います。

### 既存の記録を再計算する必要がありますか？

今回の公開で、v2の構造一覧表の計算式や完了済みの計算結果は変わっていません。**v3の公開だけを理由にv2の記録を再計算する必要はありません。**AIが提案した符号や説明を実際の検査で使用する際には、原反応、質問段階、臨床資料全体と改めて照合する必要があります。

## なぜGPT-6 Lunaを選んだのですか？

最初から最も安価なモデル一つに決めたわけではありません。まず、それまで使用していた**GPT-5.6 Terra**の回答を基準としました。この26問の社内基準試験は、後述する大規模な公開比較とは別に実施したものです。五つの言語の代表的な質問26件を試験して32回の呼び出しを完了し、使用量基準の計算費用は約**US$0.40**でした。自動表現検査は当初25/31を通過しましたが、回答の意味が正しくても検査器が別の表現を認識できなかった事例を修正し、保存された回答を再確認すると29/31でした。この経験から、以降の数値もそのまま「臨床的正答率」とは呼びませんでした。

次に、符号化143件と解釈117件、合計**260件の合成質問**を、韓国語61・英語64・日本語47・スペイン語44・ポルトガル語44件で構成しました。通常の質問だけでなく、サポート範囲外の要求、文書に混入した指示文、後続の質問と長い対話の要約を含めました。GPT-5.6 Terra、GPT-6 Sol、GPT-6 Lunaに同じ製品指針と同じ抜粋資料を提供し、各モデルで要約を含めて290回呼び出しました。この段階の抜粋資料は、実際のアプリの質問ごとの検索とは異なっていました。

| モデル | 自動表現検査の再採点 | 290回の生成費用計算値 | 呼び出し遅延の中央値 |
| --- | ---: | ---: | ---: |
| GPT-5.6 Terra | 257/280 | US$3.553828 | 3.061秒 |
| GPT-6 Sol | 254/280 | US$2.304015 | 3.125秒 |
| GPT-6 Luna | 255/280 | US$0.130514 | 3.357秒 |

この表において、Lunaの生成費用はTerraより**96.3%低く**、自動表現検査の通過数は同程度でした。しかし、255/280を「臨床的正答255件」と読むことはできません。回答を見て検査器の否定文・数値表記・同義語処理を修正し、**すでに保存された回答のみ**を再採点したためです。必要な根拠が最初から抜粋資料に含まれておらず、モデルが安全に判断を保留した場合もありました。検索・サーバー・決済の費用もこの表には含まれていません。[初期比較記録](../../benchmarks/2026-09-23/)に言語別の数値と検査方法を公開しました。

### Jevをなぜ試験し、なぜ公開経路から外したのですか？

符号化には、定められた基準に従って候補を絞り込む判断が多く含まれます。そのため、構造化判断モデル**TypeSafe Jevが情報の十分性・質問の対象範囲・参考資料の関連性を先に検討し、GPTが検査者に説明する方式**を試験しました。原反応と計算結果はJevの判断で上書きしないようにしました。目的は、より安価な判断段階を追加することそれ自体ではなく、**有用な回答一件あたりの総費用を削減しつつ、説明の質を維持できるか**を確認することでした。

まず、JevのM決定因に関する質問30件において、有効回答30件が作成者の暫定的な期待値と一致しました。臨床の専門家が確定した正答集ではありません。10件ずつまとめた要求は成功しましたが、30件を一度にまとめた要求二件はHTTP 503となり、中継サービスと元のモデルのどちらが原因かは特定できませんでした。当時のVercel AI Gatewayのプロモーションによる請求額**US$0**は、長期運用の原価として使用しませんでした。

続いて、五つの言語の調整用10問と別の規則群の20問において、GPT-6 Sol・Luna単独とJev併用を並べて比較しました。調整用10件の自動表現検査では、Luna単独とSol単独がそれぞれ**9/10**、Jev+LunaとJev+Solがそれぞれ**8/10**でした。調整には使わず、先の260問の評価集に含まれていた20問では、Luna単独**17/20**、Sol単独**15/20**、両方の併用構成はそれぞれ**19/20**でした。後者の高い数値は臨床的優位の証拠ではありませんでした。Cnの計算のように単独回答も正しかったにもかかわらず検査器が表現を見逃した事例があり、韓国語のDVに関する質問ではすべての構成が必要な規則を検索できず判断を保留しました。保存された80回答のAI判読では重大な誤りは確認されませんでしたが、**独立した臨床検証ではなく、併用の意味上の利点も確認されていません。**

Jev+Luna 10件の直接単価を仮定した費用**US$0.010538**は、Luna単独の**US$0.008627**より大きくなりました。別の20件も**US$0.017494**対**US$0.011021**でした。いずれもJevの公開直接単価をトークンに適用した*仮定値*であり、失敗分の費用は含まれていません。実際のTypeSafe直接アカウントも準備されておらず、一部のJev要求のエラー・費用は最終的に確認されませんでした。この条件でJevを正式サービスに接続すると、削減と品質改善を立証できていない複雑さだけを加えることになりかねませんでした。したがって、**v3.0.0はJevを使用しません。**[Jev単独・併用の要求別経緯](../../benchmarks/2026-09-23/)と失敗も併せて残しておきます。

### Lunaが実際のアプリでも回答できるかを再度確認しました

初期試験の固定抜粋資料の代わりに、実際のアプリのように質問ごとに関連する参照資料を検索する試験を追加しました。五つの言語で符号化・解釈各1件をGPT-5.6 TerraとGPT-6 Luna標準区分で交差比較したところ、両モデルとも自動基準で**10/10**でした。検索と生成を合わせた10件の計算費用は、Terra **US$0.226730**、Luna **US$0.011580**でした。Lunaの最初の文字が表示されるまでの時間の中央値は**7.314秒**で、Terraの**2.392秒**より長くなりました。費用だけを見て速度差を隠すことはしませんでした。

より高速なLuna **Fast**も比較しました。生成のみを測定した最初の文字までの中央値は標準**5.582秒**、Fast **2.994秒**でしたが、該当する生成費用は**US$0.010000 → US$0.035559**に増加しました。実際の検索を含む30原事例×3回の比較で、Luna Fastの計算費用はTerraより95.33%低かった一方、最初の文字までの中央値は2.024秒から2.652秒に延びました。Claudeによる最初の反復のAI判読では、80点未満の回答はTerraが0/30、Luna Fastが4/30でした。**その結果はFastの試験であり、公開されたLuna標準区分の速度や原価ではありません。**私たちは費用と回答内容を優先し、標準区分で公開しました。

![実際の資料検索を含むGPT-5.6 Terra標準とGPT-6 Luna Fastの費用および最初の文字までの遅延の比較。発売したLuna標準区分の実測ではありません](../../benchmarks/2026-09-24/retrieval-trial.svg)

Lunaの保存回答280件と要約10件も読み直しました。回答280件の内部AI判読は、**正常217件、安全だが未完成35件、自動検査の誤検出15件、根拠不足による保留12件、軽微な出典の誤認1件**でした。検討入力から過去の要約が欠落していたり、文字エンコーディングが破損していた最初の判読は根拠として使用せず、再確認しました。Claude Fable 5.1による別途のAI検討も、その実際の出典誤りを見逃しました。したがって、AI同士で一致したという理由で回答を臨床的に承認することはしませんでした。

低い反応数の説明、言語別の表現、欠落した参照資料、利用者の訂正と以前の判断の撤回履歴を中心に、指針・検索・要約を一つずつ調整しました。韓国語で改善された文章を五つの言語にそのまま押し込むのではなく、各言語で再度比較しました。低反応数を説明するスペイン語の回答一件は補正後にAI検討の最低点が76点から82点に上がりましたが、他の言語で効果のなかった修正は元に戻しました。要約では英語・ポルトガル語の撤回履歴の欠落が見られ、その調整後も一部の未解決の質問が抜け落ち、韓国語の後続回答では異なる文字体系が混在した事例も確認しました。[後続検証記録](../../benchmarks/2026-09-24/)に言語別の試験、費用、元に戻した変更と残された問題を記載しました。

## 公開した試験費用と読み方

初期の三つのGPTモデルによる290回ずつ合計870回の生成費用計算値は**US$5.988357**です。これは上の表の三つの金額を合計した値です。Jevの当時の無料プロモーションによる請求額は長期単価ではなく、[初期比較記録](../../benchmarks/2026-09-23/)の併用表にはTypeSafe直接単価の*推定*を別途記載しました。その後、Luna関連の保存された実行バッチ26件のOpenAI使用量基準の計算額は**US$2.369002**、Claude CLIの表示定価換算額は**US$117.300407**です。これらを実際のカード請求額として加算することはしません。先行する比較、記録されなかった費用と失敗した要求、サーバー・決済の運用費は、この26件のバッチに含まれていません。[非識別化した費用集計](../../benchmarks/2026-09-24/luna-cost-inventory.json)に含まれる範囲を明示しました。

自動表現検査、AIによる回答判読、実際の臨床専門家による検討は、それぞれ異なるものです。特に、開発中にすでに検討した質問での改善スコアは、初めて見る患者資料や新しい質問において同じ品質を保証するものではありません。選択したLuna標準区分において、五つの言語・すべての業務の新しい独立事例を二回通過する評価は完了していません。情報不足時に保留する回答だけでなく、回答できるにもかかわらず過度に保留する回答も、引き続き改善の対象です。

運用サイトでは、合成アカウントで符号化・解釈アシスタントの回答とLive決済画面の生成を確認しました。独立した臨床専門家による検討も完了していません。確認された欠陥は取引記録と原文の根拠に基づいて修正し、回答品質と費用を後続リリースで引き続き記録していきます。

利用規約とプライバシーポリシーは**2026-09-24**から施行します。v3のソースとAI指針は、秘密鍵・臨床記録・第三者資料の権利を検討した範囲から公開します。このリリースノートとベンチマークは、運用ソース全体の公開完了を意味するものではありません。

[モデルと検討の記録](../../benchmarks/MODEL-PROVENANCE.md)には、試験とこの文書で使った正確なモデル名、確認できた推論設定・処理区分、役割、記録が残っていない設定をまとめました。韓国語原稿の作成と根拠の照合にはOpenAI Codexを、他の四言語の翻訳原稿と別途のAIによる文章・事実確認にはClaude Fable 5.1を使いました。AIによる確認を臨床専門家による検討とは表示していません。
