# [2026-09-24] v3.0.0 メジャーリリース — AI支援を備えた有料Webアプリ

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exner v3.0.0では、ロールシャッハ包括システムの符号化と構造一覧表の解釈について、AI支援と自由に対話できます。新しいWebアプリは[exner.app](https://exner.app)で提供します。AIの回答は検討のための参考情報です。原反応と質問段階の記録に基づく最終的な符号化・解釈は、臨床の専門家が行います。

## 何が変わりましたか？

- Googleアカウントで登録し、AIへの情報送信に別途同意すると、符号化支援と解釈支援を利用できます。両方ともGPT-6 Lunaを推論レベル`medium`、標準処理区分で使用します。Jevも検討しましたが、v3.0.0の回答経路には採用していません。
- 質問に関連する参考資料を検索し、長い対話では前の内容を要約して後続の質問に渡します。要約やAI回答が原記録や計算機で確認した結果を書き換えることはありません。情報が足りない場合は追加確認を求めることがあります。
- 画面と参考資料は韓国語、英語、日本語、スペイン語、ブラジル・ポルトガル語に対応します。各言語の回答品質は引き続き改善します。五言語すべてで、あらゆる臨床判断が同じ程度に完成しているとは主張しません。
- 購読料は月額**US$3.99**、年額**US$42.99**です。他通貨での請求額と税金は決済画面およびカードの条件によります。利用量は固定の質問回数ではなくAI処理原価の枠で管理します。残りの利用量と購読状態はアプリで確認できます。

## 以前の記録を再計算する必要はありますか？

今回の公開でv2の構造一覧表の計算式や完了済みの計算結果は変わりません。この公開を理由にv2の記録を再計算する必要はありません。ただし、AIが提案する符号や説明は確定した採点結果ではありません。実際の検査では、原反応、質問段階、臨床資料全体と照合してください。

## 根拠と限界

公開前にGPT-5.6 Terra、GPT-6 Sol、GPT-6 Luna、Jevを**合成事例**で比較しました。言語別の符号化・解釈・要約、実際の資料検索、回答時間、使用量を別々に確認しました。Claude Fable 5.1による別のAI検討も行いました。表現を調べる自動検査を臨床的正答率とは見なさず、AI検討を臨床専門家による独立検討とは表示しません。正確なモデル名、数値、費用計算、失敗と未完成の回答は[初期モデル比較](../../benchmarks/2026-09-23/)と[公開設定の後続検証](../../benchmarks/2026-09-24/)に記載します。

運用サイトでは、合成アカウントで両方のAI支援の回答とLive決済画面の作成を確認しました。**公開時点では、新規登録、カード決済後の利用権、解約・返金までの全過程を実際の取引で確認していません。** 問題が見つかれば取引と利用権の記録を照合して修正します。回答に対する独立した臨床専門家の検討と、一部の多言語回答の未完成も今後の課題です。

利用規約とプライバシーポリシーの施行日は**2026-09-24**です。AIへの情報送信への同意は購読とは別で、撤回できます。v3のソースとプロンプトは、秘密情報、臨床記録、第三者の権利を確認した範囲から順次公開します。このリリースノートとベンチマークの公開は、運用ソース全体の公開完了を意味しません。
