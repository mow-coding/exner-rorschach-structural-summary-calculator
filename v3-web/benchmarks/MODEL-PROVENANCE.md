AI review is not clinical expert review.

**Recording rule for subsequent runs.** Save the exact model ID returned by the provider, request-level reasoning/thinking setting, service tier, prompt/configuration revision, input/output usage, response status, and price table or billing source with the result. If any field is absent, mark it unknown and do not present an observed benchmark as though the missing value had been measured. Do not transfer a Fast result to the Standard release configuration. Include failed requests in the run ledger even when the charge is unresolved.

The release note reports the recorded costs for earlier tests. The additional editorial CLI list-price equivalent for this publication was **US$8.06690200** across the two phases above; it is separate from the historical `US$117.300407` Claude figure in the 26-run development inventory. Neither number should be presented as an independently verified cash charge.
