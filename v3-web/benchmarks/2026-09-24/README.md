## 처음 비교를 어떻게 읽었나요?

초기 시험은 260개 합성 사례에서 GPT-5.6 Terra, GPT-6 Sol, GPT-6 Luna에 각각 답변 검사 280개와 요약을 포함한 290회 호출을 수행했습니다. 같은 지침과 고정 참고 발췌 3개를 제공했으므로 실제 제품의 질문별 상위 8개 검색과 다릅니다. 저장 답변을 개선된 자동 검사기로 다시 채점한 수치는 GPT-5.6 Terra **257/280**, GPT-6 Sol **254/280**, GPT-6 Luna **255/280**입니다. 표현 검사 통과 수이지 임상 정답률이 아닙니다. 사용량×공개 단가로 계산한 각 290회 생성 비용은 GPT-5.6 Terra **US$3.553828**, GPT-6 Sol **US$2.304015**, GPT-6 Luna **US$0.130514**이며 검색·요약 외 인프라·실패 비용은 포함하지 않습니다. Jev의 단독 및 GPT 병용 시험, 503 오류와 계산상 비용은 [초기 기록](../2026-09-23/)에 그대로 남겼습니다.

저장된 GPT-6 Luna 답변 280개와 요약 10개를 다시 판독할 때, 처음에는 실제 전달된 과거 요약 일부가 빠진 검토 입력과 UTF-8 손상된 Claude 입력을 발견했습니다. 그 판정을 최종 근거로 쓰지 않았습니다. 입력을 고쳐 다시 본 답변 분류는 **정상 217, 안전하지만 미완성 35, 자동 검사 오탐 15, 근거 부족으로 보류 12, 경미한 출처 오인 실제 오류 1**입니다. Claude Fable 5.1의 분리된 AI 검토도 일부 판정에서 달랐고 이 출처 오류를 놓쳤습니다. 따라서 어느 AI 판독도 임상 전문가 검수로 취급하지 않습니다.

## 비용과 남은 문제

[비식별 비용 집계](./luna-cost-inventory.json)는 26개 저장된 GPT-6 Luna 관련 실행 묶음에서 OpenAI 사용량 기반 계산액 **US$2.369002**, Claude CLI 표시 정가 환산액 **US$117.300407**을 각각 집계합니다. 두 값은 실제 카드 청구액이 아니며 서로 합쳐 “전체 시험비”로 표시하지 않습니다. 이 집계 밖의 GPT·Jev 시험, 비용을 기록하지 못한 요청, 검색·서버·결제 운영비는 빠져 있습니다. 중복 공급자 ID 파일은 0건이었습니다. [2026-09-23 기록](../2026-09-23/)의 기존 비교 비용은 별도 기간·구성으로 제시하고 겹치는 시험을 다시 더하지 않습니다.

출시 설정은 GPT-6 Luna 표준 `medium`이며 Fast 비용·속도를 제품 실측으로 전용하지 않습니다. 질문별 검색 누락, 낮은 반응수의 과도한 보류, 일부 언어의 얕은 설명, 철회 이력·미해결 질문 누락, 다른 문자체계 혼입을 회귀 항목으로 남겼습니다. 원래 계획의 새로운 독립 30원사례 × 5언어 전체 두 차례 최종 평가는 완료하지 않았습니다. 독립 임상 전문가 검토도 완료됐다고 표시하지 않습니다. 따라서 이 자료는 모델 선택의 공개 근거와 한계를 함께 보여주는 **개발·운영 초기 증거**입니다.
