## 숫자를 어떻게 읽어야 하나요?

자동 검사는 일부 답변에서 **뜻이 맞아도 지정된 표현이 없다는 이유로 실패**했습니다. 예를 들어 일본어의 “두 코드를 모두 기록하지 않는다”는 문장이 금지 어구 검사에 걸렸고, 계산값 `Lambda: 0.25`는 등호를 요구하는 검사에 걸렸습니다. 또 시험용 참고자료 선별이 필요한 규칙을 빠뜨려 모델이 판단을 보류한 사례도 있었습니다. 그러므로 위의 250/280 같은 수치는 **임상 정답률이나 모델 순위가 아닙니다.** Cn 계산 경계, 다른 검사체계 혼합 거절, 진단 단정 방지와 후속 질문의 대표 답변을 원문 및 규칙과 대조했지만, 전체 840개 생성 답변에 대한 독립 임상 검수는 아직 없었습니다.

Jev는 30개의 M 결정인 질문에서 유효 답변 30개가 작성자의 **임시 기대값**과 일치했습니다. 임상 전문가가 확정한 정답지는 아닙니다. Gateway로 10개 판단을 묶은 요청 3회는 성공했고, 30개를 한 요청에 묶은 시도 2회는 HTTP 503이었습니다. 오류가 Gateway에서 시작됐는지 TypeSafe에서 시작됐는지 확인되지 않았습니다. [Vercel의 Jev 무료 프로모션](https://vercel.com/ai-gateway/models/jev)은 2026-09-25 종료 예정이어서 시험 청구액 US$0을 장기 비용으로 쓰지 않았습니다. [TypeSafe 직접 공개 단가](https://docs.typesafe.ai/models)는 입력 백만 토큰당 US$0.042, 출력 무료입니다. 30개 개별 유효 호출의 입력 42341토큰에 단순 적용한 비용은 **US$0.001778322**이며 실제 청구액이 아닌 가정입니다.

## Jev와 GPT를 함께 쓴 조정용 시험

이후 **한국어·영어·일본어·스페인어·포르투갈어에서 각 2건**, 총 10개 합성 질문을 네 구성에 넣어 40개 GPT 답변을 얻었습니다. Na/Bt/Ls 규칙과 진단·치료·법정 결론의 근거 경계만 다룬 작은 조정용 묶음입니다. Jev는 자료 충분성·요청 범위·관련 참고자료를 한 번에 판단했고, GPT의 원문과 계산값은 유지했습니다. 아래 비용은 10건 전체의 사용량 기준 GPT 계산값에, 병용에는 [TypeSafe 직접 공개 단가](https://docs.typesafe.ai/models)로 계산한 Jev **US$0.001746**을 더한 것입니다. 실패 비용은 제외했습니다.

| 구성, GPT 추론 medium | 10건 비용 | 자동 계약 통과 |
|---|---:|---:|
| GPT-6 Sol 단독 | US$0.163943 | 9/10 |
| GPT-6 Luna 단독 | US$0.008627 | 9/10 |
| Jev + GPT-6 Sol | US$0.172066 | 8/10 |

**이 형태의 병용은 절감이 아니었습니다.** 시험기가 Jev 응답 1건을 형식 오류로 기록했지만 원문을 보존하지 못해 원인은 불명확하고, HTTP 503도 2건 발생해, 자동 재시도 없이 비용 미확인 실패로 기록했습니다. 빠진 답변은 별도 수동 시험으로 채웠습니다. 자동 계약에는 올바른 다국어 설명을 놓친 거짓 실패가 남아 있으므로 표의 점수를 임상 정답률로 읽지 마세요. 같은 Jev 판단을 재사용한 GPT `low` 추론 시험에서는 일본어 Jev+GPT-6 Luna가 나이가 없는 자료의 S-CON을 기준 미해당처럼 표시해, 낮은 추론량을 출시 후보에서 제외했습니다. [요청별 집계](./results-hybrid-pilot.json)는 원문·인증키·고객자료를 담지 않습니다.

## 별도 규칙군 검증

AI가 80개 답변 원문을 좁은 규칙 기준에 대조한 결과, Cn 20/20, GHR/PHR 20/20, 검사체계 혼합 20/20, DV 16/20은 기준을 충족했습니다. 한국어 DV 4/20은 필요한 규칙 검색이 빠져 안전하게 보류했지만 질문을 끝내지 못했습니다. 이 내부 판독에서 확인된 중대 오류는 0/80입니다. **이는 AI 검토이며 독립 임상 검수나 실제 검사 정확도가 아닙니다.** 구성 간 의미상 우위도 확인되지 않았습니다.

당시의 합성 사례만으로 GPT-6 Sol과 GPT-6 Luna의 제품 적합성을 확정할 수 없었습니다. 이후 실제 제품 검색과 사용량 정산을 포함한 시험을 추가했고, Jev 도입은 유보했습니다. 독립 임상 검토와 모든 실패 비용의 최종 대조는 여전히 남아 있습니다.
