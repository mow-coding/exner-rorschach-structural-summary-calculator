## 数値の読み方と限界

自動検査には、**意味が正しい回答でも指定の表現がないために失敗**したものがあります。例えば「二つのコードを両方記録しない」という日本語の否定文が禁止語句に一致し、`Lambda: 0.25`は等号を要求する検査に一致しませんでした。また、試験用の参照資料選択が必要な規則を落とし、モデルが判断を保留した事例もあります。したがって250/280などの数値は**臨床的正答率でもモデル順位でもありません**。Cnの計算境界、他の検査体系との混同の拒否、診断の断定、後続質問について代表的な回答を原記録や規則と照合しましたが、生成された回答840件の全件を独立した臨床専門家が確認したわけではありません。

JevではM決定因に関する質問30件に対し、有効な回答30件が作成者の**暫定的な期待値**と一致しました。臨床専門家が検証した正答表ではありません。Gatewayで判断10件ずつの要求3回は成功し、判断30件を一度に送った2回はHTTP 503でした。GatewayとTypeSafeのどちらに起因するかは特定できていません。[VercelのJev無料プロモーション](https://vercel.com/ai-gateway/models/jev) は2026-09-25に終了予定なので、試験時のUS$0を長期費用には使いません。[TypeSafeの直接利用の公開料金](https://docs.typesafe.ai/models) は入力百万トークン当たりUS$0.042で、出力は無料です。個別の有効な呼び出し30回で使用した入力42341トークンに適用すると**US$0.001778322**です。これは請求額ではなく試算です。
