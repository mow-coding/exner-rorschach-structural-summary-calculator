# Exner 로샤 종합체계 구조요약 계산기

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exner는 로샤 종합체계의 부호화와 구조요약 검토를 돕는 웹앱입니다. 현재 제공하는 **v3.0.0**에서는 계산기와 함께 AI 도우미에게 자유롭게 질문할 수 있습니다. AI가 제안한 부호와 설명은 참고자료이며, 원반응과 질문단계 기록을 바탕으로 한 최종 판단은 검사자가 맡습니다.

## 이용하기

- [v3 유료 웹앱](https://exner.app): 한국어·영어·일본어·스페인어·브라질 포르투갈어를 지원합니다. 구독료는 월 **US$3.99**, 연 **US$42.99**입니다.
- [v2 무료 웹앱](https://exner.yesucan.co.kr): 기존 구조요약 계산기와 본인 API 키를 연결하는 선택적 AI 기능을 계속 이용할 수 있습니다.

## v3.0.0에서 달라진 점

Google 계정과 구독을 통해 부호화·해석 도우미를 이용할 수 있습니다. 두 도우미는 **GPT-6 Luna**를 사용하며, 긴 대화에서는 앞선 내용을 요약해 다음 질문에 반영합니다. 구조요약 계산식은 v2에서 바뀌지 않았으므로 이번 출시만을 이유로 기존 기록을 다시 계산할 필요는 없습니다.

[v3.0.0 릴리즈 노트](./v3-web/releases/v3.0.0/README.md)에서 기능과 임상적 한계를, [모델 비교 기록](./v3-web/benchmarks/2026-09-23/)과 [후속 검증 기록](./v3-web/benchmarks/2026-09-24/)에서 시험 방법·결과·비용을 확인할 수 있습니다. 합성 사례의 자동 검사 결과를 임상 정확도로 해석하지 않습니다.

## 소스와 이전 버전

이 저장소에는 [v2 공개 소스](./v2-nextjs/source/), [v1 공개 소스](./v1-gas/current/)와 [전체 릴리즈 기록](./CHANGELOG.md)이 있습니다. v3 운영 소스 전체는 아직 공개되지 않았습니다. 비밀값·임상기록·타인 자료의 권리를 확인한 소스와 AI 지침을 별도 공개할 예정이며, 기존 소스의 저작권 표시는 보존합니다.

MOW(모오)가 서비스를 기획·운영합니다. 서울임상심리연구소(SICP)는 초기 계산 결과 확인과 임상 사용 관점의 검토에 기여했습니다. [감사의 말과 초기 학습 자료](./ACKNOWLEDGEMENTS.md)도 확인할 수 있습니다.

새 v3 기록의 권리 표시와 공개 범위는 [v3 고지](./v3-web/NOTICE.md)에 정리했습니다. 기존 v1·v2의 저작권 표시는 유지합니다.
