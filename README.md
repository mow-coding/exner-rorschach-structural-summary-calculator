# Exner 로샤 종합체계 구조요약 계산기

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exner는 로샤 종합체계의 부호화와 구조요약 검토를 돕는 도구입니다.

## 이전 버전

- **v1 · Google Apps Script** — 구조요약 계산 도우미로 시작했습니다. [v1 패치노트·소스 아카이브](./v1-gas/README.md)
- **v2 · Next.js** — 무료 웹앱으로 옮기고, 본인의 API 키로 쓰는 선택적 AI 기능을 더했습니다. [v2 무료 웹앱](https://exner.yesucan.co.kr) · [v2 패치노트·소스 아카이브](./v2-nextjs/README.md)

## 최신 릴리즈 v3.0.0

기존 구조요약 계산기에 Google 계정과 구독으로 이용하는 부호화·해석 도우미를 더했습니다. 두 도우미는 **GPT-6 Luna**를 사용합니다. 앱 화면과 참고자료는 한국어·영어·일본어·스페인어·브라질 포르투갈어를 지원합니다. 구조요약 계산식은 바뀌지 않았으므로 이번 출시만을 이유로 기존 기록을 다시 계산할 필요는 없습니다.

[웹앱 이용하기](https://exner.app) · 구독료 월 **US$3.99**, 연 **US$42.99**. AI의 제안은 참고자료이며, 원반응과 질문단계 기록을 바탕으로 한 최종 판단은 검사자가 합니다.

[v3.0.0 릴리즈 노트](./v3-web/releases/v3.0.0/README.md)에 기능과 한계를, [모델 비교](./v3-web/benchmarks/2026-09-23/)와 [추가 검증](./v3-web/benchmarks/2026-09-24/)에 시험 방법·결과·비용을 담았습니다. [전체 버전 기록](./CHANGELOG.md)도 볼 수 있습니다. v3 운영 소스 전체는 아직 공개되지 않았으며, 공개 자료의 권리와 범위는 [라이선스 안내](./LICENSES.md)에 정리했습니다.
