# Exner 로샤 종합체계 구조요약 계산기

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

현재 출시 버전은 **v3.0.0**입니다. Exner는 로샤 종합체계의 부호화와 구조요약 검토를 돕는 웹앱으로, 한국어·영어·일본어·스페인어·브라질 포르투갈어를 지원합니다.

[웹앱 이용하기](https://exner.app) · 월 **US$3.99** / 연 **US$42.99**

구조요약 계산기와 **GPT-6 Luna** 기반 부호화·해석 도우미를 제공합니다. AI의 제안은 참고자료이며, 원반응과 질문단계 기록을 바탕으로 한 최종 판단은 검사자가 합니다.

[v3.0.0 릴리즈 노트](./v3-web/releases/v3.0.0/README.md)에서 기능과 한계를, [모델 비교](./v3-web/benchmarks/2026-09-23/)와 [추가 검증](./v3-web/benchmarks/2026-09-24/)에서 시험 방법·결과·비용을 확인할 수 있습니다. v3 운영 소스 전체는 아직 공개되지 않았습니다. 공개 자료의 권리와 범위는 [라이선스 안내](./LICENSES.md)에 정리했습니다.
