# [2026-06-22] v2.1.0 マイナーリリース

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

v2.1.0 は、対応ブラウザでウェブアプリをインストール型アプリのように開けるようにし、公開プロジェクト RorScore をクレジットに明記し、AI がコーディングの質問に合う参照文書を先に探すように改善したリリースです。

## 要点

- Chrome・Edge などの対応ブラウザで、ウェブアプリをインストール型アプリのように開けます。
- インストール機能にはオフライン保存、プッシュ通知、バックグラウンド同期はなく、機微な評価データや AI の応答を端末に別途保存しません。
- `DQ+` のようなコーディングの質問をすると、AI は関連する採点入力の文書を先に参照します。
- 公開プロジェクト RorScore を参考資料としてクレジットに明記しました。

## インストールとデータ保管

インストール機能は、アプリのデータ保管方式や API キーの保護方針を変えません。API キーは暗号化された状態で AI 接続に使われ、接続は最長 24 時間だけ維持され、終了するとキーも削除されます。

インストールしたアプリもインターネットに接続して使い、機微な評価資料や AI の応答をオフラインに保存しません。

この変更は計算結果に影響しません。コーディングアシスタントは「DQ+ はいつ DQo や DQv/+ ではなく DQ+ とコーディングすべきか」のような質問を受けると、解釈文書より先に関連する採点入力の文書を参照します。
