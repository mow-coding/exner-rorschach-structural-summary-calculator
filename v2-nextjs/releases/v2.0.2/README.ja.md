# [2026-05-21] v2.0.2 バグ修正

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

v2.0.2 は、v2.0.1 以降に確認された構造要約 CSV の問題を修正したバグ修正です。製品の大きな方向性や AI 機能の使い方は変えておらず、結果画面からコピーまたはダウンロードするデータが、画面の構造要約の計算結果をより正確に反映するように整えました。

**構造要約の計算値そのものは変わっていないため、再計算の必要はありません。** ただし、v2.0.1 でコピーした構造要約 CSV で AI 解釈を行った場合、一部の項目が欠けたり同じ名前が重複したりした可能性があるため、v2.0.2 以降でコピーし直した値でその解釈を確認してください。ダウンロードして保管している過去の CSV も、同じ理由で作り直すほうが安全です。

## 要点

- データダウンロード画面の韓国語の項目名 `입력값 원자료 CSV` を `점수계열 원자료 CSV` に修正しました。
- `構造要約の値をコピー` ボタンでコピーされる CSV 文字列に、ヘッダーの重複や項目の欠落が生じうる問題を修正しました。
- コピーとダウンロードで同じ構造要約の項目を提供します。
- API キーでログインした AI セッションで、AI プロバイダーのキーエラーが起きたときにセッション開始のポップアップが繰り返し表示される問題を修正しました。
- OpenAI の既定の会話モデルを GPT-5.4 から GPT-5.5 に更新しました。
- 解釈アシスタントで構造要約の数値を貼り付けた際の完了表示を `入力済み ✅` に補強しました。

## 解釈アシスタントで確認すべき点

v2.0.1 の解釈アシスタントは、結果画面の `構造要約の値をコピー` ボタンでコピーした値を、解釈 AI 画面の構造要約の数値入力欄に貼り付けて会話を始める方式です。

v2.0.1 では、`D`、`Zf`、`Zd`、`GHR`、`PHR` のように複数の区画で使われる名前が、コピーしたデータの中で重複することがありました。`Single`、`Contents`、`Form Quality`、`Special Scores`、`Approach`、`Blends` のように画面に表示される一部の項目が欠けることもありました。

API キーの接続や AI 会話機能そのものの問題ではありませんでしたが、解釈アシスタントに渡される構造要約データが不完全または曖昧になる可能性がありました。

## 変更点

コピーとダウンロードで漏れなく同じ項目を提供し、名前が重複する項目も区別して表示します。

スコア系列の原資料 CSV には、計算に実際に使われた採点行だけが含まれます。カードが空の仮の行や未完成の行は除外されます。

解釈アシスタントは結果画面からコピーした構造要約データを受け付け、関係のない一般的な文章は構造要約データとして扱いません。
