# [2026-07-14] v2.2.0 マイナーリリース

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

> **現在の計算式について:** D/AdjD の極端値、EBPer の表示条件、GHR/PHR の判定順、Lower Section の `FC:CF+C` における Cn の欠落、WDA% と Afr の分母 0 の処理は v2.2.1 で修正しました。v2.2.2 では、Cn を含める計算と含めない計算を分離し、形態質（FQ）が空の未完成行の GHR/PHR 分類を補いました。計算機は年齢を入力として受け取らず、年齢制限のある解釈を求められた場合にのみ、AI の解釈会話で必要な情報を質問します。**現在の計算基準は [v2.2.2 の文書](../v2.2.2/) を確認してください。**

## はじめに確認いただく点

v2.2.0 は、計算機を中心に据えたまま、デスクトップ画面の主なメニューを左のサイドバーにまとめ、解釈アシスタントを一般的な AI 会話画面に近い形に再構成した v2.2.x の最初のリリースです。AI 回答の評価は会話の原文を保存せず、あらかじめ決めた理由だけを選ぶようにしました。

このリリースで扱った計算項目のうち追加の修正が必要だった項目は、v2.2.1 と v2.2.2 で修正しました。AI アシスタントは、Exner 包括システムの範囲外の質問や非公開情報を求める要求には答えません。

## 要点

### 共通画面とサイドバー

- 従来の上部・下部メニューを、デスクトップの固定アイコンバー、本文の上に開くサイドバー、モバイル用メニューに統合しました。
- サイドバーは本文を押しのけず、開いた状態で別のページに移動しても維持され、言語・テーマ・AI セッションの操作を一か所に集めます。
- ログイン前は AI セッションの開始のみ、ログイン後は AI セッションの終了のみを表示し、終了前に確認画面を挟みます。
- 従来の計算機のショートカット、サイドバーのショートカット、採点画面の拡大・縮小・移動方法をまとめた多言語のショートカット案内を追加しました。
- 計算機、解釈アシスタント、参照文書、サービス紹介、利用規約、プライバシーポリシー、バージョンアーカイブの背景とライト・ダークモードの色を統一しました。
- サービス・規約・プライバシーのページから、不要な外枠とページ全体のコピーボタンを削除しました。

### BYOK と解釈アシスタント

- BYOK（Bring Your Own Key）は、利用者が自分の OpenAI API キーを直接接続して任意の AI 機能を使う方式です。
- OpenAI API キーと `OpenAI GPT-5.5` の表示を同じ行に配置し、重複する題名と自動モデル選択の案内を削除して、AI 接続画面を簡潔に表示します。
- API キーは AI 接続のために暗号化された状態で最長 24 時間保持され、接続を終了すると削除されるという案内をより明確に表示しました。誤ったキーの案内が表示されても画面の大きさが揺れません。
- 解釈アシスタントを外枠カードのない全体の作業領域に変え、長い会話はページ全体ではなく会話領域の中だけでスクロールするようにしました。
- AI の回答を追う自動スクロールは、人が上へ移動すると止まり、必要なときに最新の回答へ再び移動できます。
- 回答の停止、メッセージのコピー、前の質問の位置への移動、半透明の入力欄、構造要約の貼り付け状態を追加しました。
- 利用者と AI のメッセージにコピーボタンを提供し、AI のメッセージには「役に立った」「役に立たなかった」と、あらかじめ決めた理由の選択画面を追加しました。
- AI 回答の評価には、質問・回答の原文や自由記述を残しません。役に立ったかどうか、選んだ理由、使用言語、モデル、回答が完了したかどうか、おおよその長さだけを最長 180 日保管します。

### 採点画面

- 行の移動ハンドルが表の境界で切れなくなりました。
- 通常のクリック、`Shift + クリック`、`Ctrl/Command + クリック` による複数行の選択と、行の移動プレビューが安定して動作します。
- 値のある選択ボックス、空の選択ボックス、使用できない選択ボックスが同じ大きさと配置を保ち、明暗だけで区別されるようにしました。
- 一般的なデスクトップ画面では表が 1 画面に収まり、画面が狭いときには採点領域の中だけで横に移動するように列幅を調整しました。
- `Alt + マウススクロール` はマウスの位置を中心に採点画面全体を 40〜125% の範囲で拡大・縮小し、`Ctrl + ドラッグ` は拡大した画面を移動します。
- 行の順序の案内は、表のすぐ下の青い領域に表示します。
- 下部のボタンは、左の追加・削除・案内と、中央の結果計算・入力値の初期化に整理しました。

### 参照文書とバージョンアーカイブ

- 参照文書の検索欄が検索結果と詳細文書でも消えず、検索語も次の画面に引き継がれるようにしました。
- 検索結果がないときの案内、文書分類ボタン、文書コピー完了の案内を 5 言語で揃えました。
- 参照文書の本文を外枠カードのない閲覧画面に変え、検索欄・分類・本文の中心線を揃えました。
- バージョン 2 と GAS バージョン 1 の記録を、題名を押して展開・折りたたむ形に整理し、展開時に縦スクロールバーが現れても画面が左右に揺れないようにしました。
- GAS の実行案内は、題名の横にあるキーボードでも開ける情報ヘルプに移しました。

## v2.2.0 の計算変更

v2.2.0 では次の 7 項目を修正しました。現在の計算式は、後続の v2.2.1 と v2.2.2 の修正まで反映しています。

| 項目 | 修正内容 |
| --- | --- |
| EBPer | `EA >= 4`、M と WSumC が正、比率 `>= 2.5` のときだけ表示 |
| 能動・受動運動 | `Ma-p`、`FMa-p`、`ma-p` を能動と受動の両方にそれぞれ合算 |
| `3r+(2)/R` | 反射反応 `Fr+rF` の重みを 2 から標準式の 3 に修正 |
| HVI | Zd の補助条件の境界を `> 3.0` から `> 3.5` に修正 |
| ZEst | 最後の有効境界 `Zf=50` が `173` を返すように修正 |
| D/AdjD | 負の区間で `-0` の代わりに `0` と表示 |
| Lambda | すべての反応が純粋 F のとき 0 ではなく `∞` として処理 |

計算結果の比較には、次の 4 種類の資料を使いました。

- [Essentials of Rorschach Assessment の sample computerized score reports](https://elmirmohammedmemorypsy.com/wp-content/uploads/2021/04/essentials-of-rorschach-assessment.pdf)
- [Engelman et al., "Why am I so stuck?"](https://www.therapeuticassessment.com/docs/Engelman_et_al_2016_copy.pdf)
- [Tibon Czopp et al. の健忘症候群の事例](https://pubmed.ncbi.nlm.nih.gov/23985019/) と [正誤表](https://www.tandfonline.com/doi/pdf/10.1080/13554794.2014.910345)
- 初期の v1 開発で参考にした [公開配布の 2019 年 Excel ワークブック](https://blog.naver.com/jin_k84/221539279596) の実際の数式。ワークブック内部の制作表記は `[Scoring Program] _by. Ju-Ri` で、実名を推定したり元ファイルを再配布したりしません。

出版された表と公開されたスコア列が互いに異なっていた 2 項目は、どちらか一方を唯一の正解とはしませんでした。

国ごとの集団平均は、同じスコア列の計算の正解表ではありません。文化圏の違いは計算式ではなく符号化・規準・解釈の適用に主に影響するため、韓国・日本・英語圏の資料は文化・年齢別の回答範囲を確認するために別途使いました。

## AI アシスタントの範囲

- R-PAS の一般的な解釈、MMPI の一般的な解釈、無関係な質問、非公開情報を求める要求には答えません。
- 有効な Exner の比較・鑑別の質問は、他の体系の一般的な解釈に広げず、境界を説明する範囲でのみ許可します。
- S-CON の解釈は満 15 歳以上に適用します。計算機は年齢を入力として受け取らず、S-CON の解釈を求められた AI アシスタントが必要な場合にのみ会話で年齢を確認します。
- Popular（`P`）を直接尋ねる質問には、平凡反応の参照文書を先に提示します。

自分の API キーを接続して GPT-5.5 を使う方式は維持します。AI の会話は現在のブラウザウィンドウを使っている間だけ維持され、長期的なアカウント記録として保管されません。AI は臨床家の最終判断に代わるものではなく、すべての回答の正確性を保証するものでもありません。

## 残っている限界

- この計算範囲は、可能なすべての反応の組み合わせを数学的に証明するものではありません。
- 計算機は年齢を直接入力として受け取らないため、満 14 歳以下の S-CON 解釈の保留は、使用する臨床家が確認する必要があります。
- 実際の臨床的有用性、多言語の文章品質、安全性は、資格を持つ専門家が判断する必要があります。
