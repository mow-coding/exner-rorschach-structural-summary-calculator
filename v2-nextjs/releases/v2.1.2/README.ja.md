# [2026-06-28] v2.1.2 バグ修正

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

v2.1.2 は、コーディングアシスタントと解釈アシスタントが必要な分だけ答え、途中で途切れず、臨床家の判断範囲を越えないように回答方式を調整した修正です。API キー入力画面の配置を少し整えた以外、画面構成は変えていません。

## 要点

- コーディング・解釈アシスタントの回答の長さと表示方法がより一貫して動作します。
- コーディングアシスタントは、候補コードと臨床家が確認すべき範囲をより明確に述べるようにしました。行の自動入力や自動適用と誤解されうる回答は止め、根拠が足りないときは観察情報を追加で求めます。
- 解釈アシスタントが単一の指標だけで診断・治療・法的判断を確定しないよう、回答の限界を強化しました。構造要約の値が足りない広い質問には、存在しない指標を作らず、確認の順序を案内します。
- API キー入力画面で、OpenAI のモデル名とキー入力欄を 1 行で読みやすく表示します。
