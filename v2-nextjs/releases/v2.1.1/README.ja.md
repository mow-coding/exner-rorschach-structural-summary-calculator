# [2026-06-27] v2.1.1 バグ修正

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

v2.1.1 は、採点入力画面と AI 接続手順の問題を修正したバグ修正です。Gemini/Google AI の接続を削除し、自分の API キーを接続する OpenAI 方式に単純化しました。

## 要点

- 反応メモのポップアップ内でテキストをマウスでドラッグすると、背景のクリックと誤認されてポップアップが閉じる問題を修正しました。
- コーディングアシスタントとの会話中に別の行を選んでも、既存の会話と進行中の回答が消えなくなりました。
- AI 機能は OpenAI の API キーのみを受け付け、Google Gemini の接続は提供しなくなりました。
- API キー入力画面で、モデル名とキーの案内を 1 行で読みやすく表示します。

## AI 接続と採点画面

AI 機能は OpenAI の API キーのみを受け付けるようになりました。以前の Google・Gemini のキーを入力すると、OpenAI のキーが必要である旨を案内します。API キーは暗号化された状態で AI 接続に使われ、接続は最長 24 時間だけ維持され、終了するとキーも削除されます。

コーディングアシスタントは選択中の行を参照しますが、別の行に移動しても既存のメッセージは消えません。会話を保ったまま、別の行を参照して続けて質問できます。

反応メモのポップアップの修正は、採点値の計算結果には影響しません。入力中にポップアップを閉じる条件だけをより正確にしました。
