# エクスナー・ロールシャッハ包括システム構造一覧表計算機

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

現在のリリースは**v3.0.0**です。Exnerは、ロールシャッハ包括システムの符号化と構造一覧表の確認を支援するウェブアプリです。韓国語、英語、日本語、スペイン語、ブラジルポルトガル語に対応しています。

[ウェブアプリを使う](https://exner.app) · 月額**US$3.99**／年額**US$42.99**

構造一覧表の計算機に加え、**GPT-6 Luna**を使う符号化・解釈アシスタントを提供します。AIの提案は参考情報であり、原反応と質問段階の記録に基づく最終判断は検査者が行います。

機能と限界は[v3.0.0リリースノート](./v3-web/releases/v3.0.0/README.ja.md)をご覧ください。[モデル比較](./v3-web/benchmarks/2026-09-23/)と[追加検証](./v3-web/benchmarks/2026-09-24/)には、試験方法、結果、費用を記載しています。v3の運用ソース全体はまだ公開していません。公開資料の権利と範囲は[ライセンス案内](./LICENSES.md)にまとめています。
