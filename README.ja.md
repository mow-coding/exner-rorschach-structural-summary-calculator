# エクスナー・ロールシャッハ包括システム構造一覧表計算機

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exnerは、ロールシャッハ包括システムの符号化と構造一覧表の確認を支援するツールです。

## 以前のバージョン

- **v1 · Google Apps Script** — 構造一覧表の計算を支援するツールとして始まりました。[v1のリリースノートとソースアーカイブ](./v1-gas/README.ja.md)
- **v2 · Next.js** — 無料のウェブアプリとなり、ご自身のAPIキーで使う任意のAI機能を追加しました。[無料のv2ウェブアプリ](https://exner.yesucan.co.kr) · [v2のリリースノートとソースアーカイブ](./v2-nextjs/README.ja.md)

## 最新リリース v3.0.0

従来の構造一覧表計算機に、Googleアカウントとサブスクリプションで利用できる符号化・解釈アシスタントを加えました。どちらも**GPT-6 Luna**を使用します。アプリの画面と参考資料は韓国語、英語、日本語、スペイン語、ブラジルポルトガル語に対応しています。構造一覧表の計算式は変わっていないため、今回の公開だけを理由に既存の記録を再計算する必要はありません。

[ウェブアプリを使う](https://exner.app) · 料金は月額**US$3.99**、年額**US$42.99**です。AIの提案は参考情報であり、原反応と質問段階の記録に基づく最終判断は検査者が行います。

機能と限界は[v3.0.0リリースノート](./v3-web/releases/v3.0.0/README.ja.md)をご覧ください。[モデル比較](./v3-web/benchmarks/2026-09-23/)と[追加検証](./v3-web/benchmarks/2026-09-24/)には、試験方法、結果、費用を記載しています。[全バージョンの記録](./CHANGELOG.ja.md)も確認できます。v3の運用ソース全体はまだ公開していません。公開資料の権利と範囲は[ライセンス案内](./LICENSES.md)にまとめています。
