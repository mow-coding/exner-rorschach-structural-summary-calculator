# エクスナー・ロールシャッハ包括システム構造一覧表計算機

[한국어](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Português (Brasil)](./README.pt-BR.md)

Exnerは、ロールシャッハ包括システムの符号化と構造一覧表の確認を支援するウェブアプリです。現在の**v3.0.0**では、計算機に加えて、続けて質問できるAIアシスタントを利用できます。AIが提案するコードや説明は参考情報です。原反応と質問段階の記録に基づく最終判断は検査者が行います。

## アプリを使う

- [有料のv3ウェブアプリ](https://exner.app) ：韓国語、英語、日本語、スペイン語、ブラジルポルトガル語に対応します。料金は月額**US$3.99**、年額**US$42.99**です。
- [無料のv2ウェブアプリ](https://exner.yesucan.co.kr)：従来の構造一覧表計算機を引き続き利用できます。ご自身のAPIキーを使う任意のAI機能もあります。

## v3.0.0で変わったこと

Googleアカウントとサブスクリプションで、符号化と解釈のアシスタントを利用できます。どちらも**GPT-6 Luna**を使用します。長い対話では、それまでの内容を要約して次の質問に反映します。構造一覧表の計算式はv2から変わっていないため、今回の公開だけを理由に既存の記録を再計算する必要はありません。

機能と臨床上の限界は[v3.0.0リリースノート](./v3-web/releases/v3.0.0/README.ja.md)をご覧ください。[モデル比較](./v3-web/benchmarks/2026-09-23/)と[追加検証](./v3-web/benchmarks/2026-09-24/)には、方法、結果、費用を記載しています。合成事例の自動検査結果は臨床的な正答率ではありません。

## ソースコードと以前のバージョン

このリポジトリには、[v2の公開ソース](./v2-nextjs/source/)、[v1の公開ソース](./v1-gas/current/)、[全リリースの記録](./CHANGELOG.ja.md)があります。v3の運用ソース全体はまだ公開していません。秘密情報、臨床記録、第三者の資料に関する権利を確認した上で、ソースとAIへの指示を別途公開する予定です。既存の著作権表示は維持します。

MOW（モオ）がサービスを企画・運営します。ソウル臨床心理研究所（SICP）は、初期の計算結果の確認と臨床利用の観点からの検討に貢献しました。[謝辞と初期の学習参考資料](./ACKNOWLEDGEMENTS.ja.md)もご覧いただけます。

新しいv3記録の権利表示と公開範囲は[v3の告知](./v3-web/NOTICE.md)にまとめました。従来のv1・v2の著作権表示は維持します。
